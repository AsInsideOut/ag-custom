Кастомный интерфейс, цвета, обои и фоновый автопатчер для Antigravity (Windows)

Возможности:
- Смена цвета интерфейса на любой свой (палитра / HEX / пресеты), отдельный цвет сайдбара, контраст панелей.
- Обои на задний фон: картинка, GIF или видео (выбор файла с ПК или URL), затемнение, прозрачность панелей, Blur.
- Маскот Anty: сидит на поле ввода, гуляет с анимацией ходьбы, реагирует на ввод и работу агента, спит при бездействии, гладится курсором (удержи 2 сек и поводи в стороны).
- Обратимый перевод интерфейса на русский.
- Визуальное переименование любых моделей и имени аккаунта на главном экране.
- Скрытие / показ кнопки «Стиль» по горячей клавише (по умолчанию Alt+S, можно переназначить).
- Сохранение всех настроек и обоев на диск (%USERPROFILE%\.gemini\antigravity\).
- Фоновый сервис автообновления: автоматически подхватывает новые версии Antigravity и перепатчивает их.

Установка:
1. Распакуй весь архив в любую постоянную папку (не запускай прямо из архива и не удаляй папку после установки — оттуда работает фоновый сервис).
2. Запусти apply_custom_ui.bat (требуется Python в PATH).
   - Скрипт динамически пропатчит установленный Antigravity (сохранив резервную копию app.asar.bak),
   - добавит фоновый сервис в автозагрузку Windows и запустит его,
   - перезапустит Antigravity.

Откат и удаление сервиса:
- Запусти restore_original_ui.bat.
