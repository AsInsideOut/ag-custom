# Antigravity Custom UI (`ag-custom`)

Кастомизация интерфейса **Google Antigravity** (Windows) с сохранением родного чистого дизайна, динамическим патчингом под любые обновления и скрытым фоновым сервисом. Спасибо G4merCybber (telegram) за изначальный скрипт❤️

## Возможности

- **Свой цвет интерфейса и стили стекла** — палитра, ввод HEX вручную, 10 готовых тёмных пресетов, настройка контраста панелей, **отдельный цвет сайдбара**, режим **отдельной «плавающей» боковой панели**, **прозрачная верхняя панель и системные кнопки окна** поверх обоев, а также переключатель стиля стекла:
  - **🌫 Frosted Glass** — классическое матовое стекло;
  - **💧 Liquid Glass** — оптическое стекло с SVG-преломлением (`feTurbulence` + `feDisplacementMap`), усиленной светопередачей, глянцевой кромкой и бликами (с мягким сбалансированным профилем для боковой панели).
- **Spotify Dynamic Island** — компактный плавающий островок по центру верхней панели:
  - появляется автоматически при открытом окне Spotify и скрывается при его закрытии;
  - мгновенно отображает текущий трек и исполнителя, 4-полосный живой аудио-визуализатор в реальном времени (Windows WASAPI) и плавно раскрывается при наведении/клике;
  - управление воспроизведением (назад / пауза / вперёд), кликабельный прогресс-бар, режимы повтора (выкл / плейлист / один трек) и кнопка **«В избранное»** с сохранением состояния.
- **Обои на задний фон** — картинка (`.jpg`, `.png`, `.webp`), анимированный `.gif` или видео (`.mp4`, `.webm`), выбор файла с ПК или по прямой ссылке (URL). Настройка затемнения, прозрачности панелей и размытия (`Blur`).
- **Погодные эффекты с физикой (🌧 Дождь / ❄ Снег)**:
  - **Дождь** — капли с градиентным хвостом, порывами ветра и параллаксом глубины; при попадании сверху на поле ввода промпта или сайдбар дают всплеск с кольцом и остаются лежать капельками с бликом, а при попадании в бок — реалистично соскальзывают по стенке с влажным следом и срываются с нижнего угла;
  - **Снег** — 3 вида кристаллических 6-лучевых снежинок с вращением и порывами ветра, которые оседают на верхних гранях и сползают с боков;
  - настраиваются **интенсивность** (`40%–200%`) и **скорость падения** (`30%–250%`).
- **Маскот Anty** — пиксельный компаньон в духе Clawd:
  - сидит на верхней границе поля ввода промпта и иногда гуляет по интерфейсу с покадровой анимацией ходьбы;
  - реагирует на работу: стоит в `idle`, смотрит с `?` пока печатаешь, «кодит» на мини-ноутбуке пока работает агент, радуется с сердечком по завершении и засыпает при бездействии;
  - **можно гладить курсором** (удерживай курсор на Anty 2 секунды и поводи в стороны — он замурлычет и полетят сердечки), кликать, перетаскивать мышкой и возвращать на промпт двойным кликом;
  - настраивается в окне `Стиль` (вкл/выкл, прогулки, размер `36–96px`).
- **Визуальное переименование моделей** — можно переименовать любую модель из списка (и добавлять свои правила замены).
- **Визуальная смена имени аккаунта** — меняет имя в приветствии на главном экране с кнопкой быстрого возврата.
- **Обратимый перевод интерфейса на русский** — переводит меню, контекстные списки, права доступа, правую панель и относительное время в сайдбаре (`2м.`, `3ч.`, `1д.`, `2мес.`, `сейчас`); включается и выключается на лету без перезагрузки.
- **Перевод заголовков мыслей и шагов агента (Google Translate)** — отдельная обратимая опция без API-ключа (пакетные запросы + авто-фоллбек на MyMemory + кеш на диске): переводит заголовки шагов (`Работал 2м`, `Изменён ...`, `Выполнено: ...`), не трогая код, вывод терминала и названия моделей.
- **Скрытие кнопки «Стиль» по горячей клавише** — по умолчанию `Alt + S` (работает на любой раскладке, можно переназначить на любую клавишу или комбинацию).
- **Сохранение настроек и обоев на диск** — все параметры и загруженные обои хранятся в `%USERPROFILE%\.gemini\antigravity\` и не сбрасываются при перезапуске или смене локального порта.
- **Фоновый автопатчер** — скрытый сервис в автозагрузке Windows отслеживает обновления Antigravity и автоматически перепатчивает новую версию `app.asar` без отката версии приложения.

## Требования

- Windows 10 / 11
- Установленный **Antigravity** (`%LOCALAPPDATA%\Programs\antigravity\`)
- **Python 3** в `PATH` (для динамического патчера `patch_asar.py`)

## Установка

1. Скачай готовый архив `agcustom.zip` со страницы **[Releases](../../releases)** (или склонируй репозиторий).
2. Распакуй в любую постоянную папку (например, `C:\agcustom` — **не удаляй папку после установки**, из неё работает фоновый сервис).
3. Запусти **`apply_custom_ui.bat`**:
   - скрипт остановит старый фоновый сервис (если был запущен);
   - динамически пропатчит установленный `app.asar` (предварительно сделав бэкап `app.asar.bak`);
   - добавит фоновый сервис в автозагрузку Windows (`HKCU\...\Run\QusaAntigravityUI`) и запустит его;
   - перезапустит Antigravity с поддержкой drag-and-drop (Medium Integrity Level).

## Управление

- Нажми кнопку **`Стиль`** в нижней части бокового меню (справа от **`Настройки`** / `Settings`), чтобы открыть панель настроек. При свёрнутом сайдбаре кнопка остаётся доступной в левом нижнем углу.
- Нажми **`Alt + S`** (или свою назначенную комбинацию), чтобы скрыть / снова показать кнопку **`Стиль`**.

## Откат и удаление сервиса

Запусти **`restore_original_ui.bat`** — он остановит фоновый сервис, удалит его из автозагрузки Windows, восстановит оригинальный `app.asar.bak` и перезапустит чистый Antigravity.

## Структура файлов

| Файл | Назначение |
| --- | --- |
| `apply_custom_ui.bat` / `apply_first.ps1` | Установка / обновление патча и запуск фонового сервиса |
| `restore_original_ui.bat` / `restore_first.ps1` | Откат к оригинальному UI и удаление сервиса |
| `patch_asar.py` | Динамический патчер Electron `app.asar` (с пересчётом SHA-256 `integrity`) |
| `qusaCustomUI.js` | Логика кастомного интерфейса, тем, стилей стекла, обоев, Spotify Dynamic Island, погоды, маскота и переводов |
| `qusa_spotify_bridge.ps1` | Фоновый PowerShell-мост для Spotify (GSMTC + WASAPI аудио-визуализатор + управление воспроизведением) |
| `qusa_watcher.ps1` / `start_watcher_hidden.vbs` | Скрытый фоновый сервис автообновления патча |
| `launch_medium.ps1` | Перезапуск Antigravity с Medium IL (сохраняет drag-and-drop) |
| `assets/` | Исходные SVG-спрайты маскота `assets/anty/` |
