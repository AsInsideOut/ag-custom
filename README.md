# Antigravity Custom UI (`ag-custom`)

Кастомизация интерфейса **Google Antigravity** (Windows) с сохранением родного чистого дизайна, динамическим патчингом под любые обновления и скрытым фоновым сервисом.

## Возможности

- **Свой цвет интерфейса** — палитра, ввод HEX вручную, 10 готовых тёмных пресетов, настройка контраста панелей и **отдельный цвет сайдбара**.
- **Обои на задний фон** — картинка (`.jpg`, `.png`, `.webp`), анимированный `.gif` или видео (`.mp4`, `.webm`), выбор файла с ПК или по прямой ссылке (URL). Настройка затемнения, прозрачности панелей и размытия (`Blur`).
- **Визуальное переименование моделей** — можно переименовать любую модель из списка (и добавлять свои правила замены).
- **Визуальная смена имени аккаунта** — меняет имя в приветствии на главном экране с кнопкой быстрого возврата.
- **Обратимый перевод интерфейса на русский** — включается и выключается на лету без перезагрузки.
- **Скрытие кнопки «Стиль» по горячей клавише** — по умолчанию `Alt + S` (работает на любой раскладке, можно переназначить на любую клавишу или комбинацию).
- **Сохранение настроек и обоев на диск** — все параметры и загруженные обои хранятся в `%USERPROFILE%\.gemini\antigravity\` и не сбрасываются при перезапуске или смене локального порта.
- **Фоновый автопатчер** — скрытый сервис в автозагрузке Windows отслеживает обновления Antigravity и автоматически перепатчивает новую версию `app.asar` без отката версии приложения.

## Требования

- Windows 10 / 11
- Установленный **Antigravity** (`%LOCALAPPDATA%\Programs\antigravity\`)
- **Python 3** в `PATH` (для динамического патчера `patch_asar.py`)

## Установка

1. Скачай готовый архив `agcustom.zip` со страницы **[Releases](../../releases)** (или склонируй репозиторий).
2. Распакуй в любую постоянную папку (например, `C:\agcustom` — **не удаляй папку после установки**, из неё работает фоновый сервис).
3. Запусти **`apply_custom_ui.bat`**:
   - скрипт остановит старый фоновый сервис (если был запущен);
   - динамически пропатчит установленный `app.asar` (предварительно сделав бэкап `app.asar.bak`);
   - добавит фоновый сервис в автозагрузку Windows (`HKCU\...\Run\QusaAntigravityUI`) и запустит его;
   - перезапустит Antigravity с поддержкой drag-and-drop (Medium Integrity Level).

## Управление

- Нажми кнопку **`Стиль`** в правом верхнем углу (её можно перетаскивать мышкой), чтобы открыть панель настроек.
- Нажми **`Alt + S`** (или свою назначенную комбинацию), чтобы скрыть / снова показать кнопку **`Стиль`**.

## Откат и удаление сервиса

Запусти **`restore_original_ui.bat`** — он остановит фоновый сервис, удалит его из автозагрузки Windows, восстановит оригинальный `app.asar.bak` и перезапустит чистый Antigravity.

## Структура файлов

| Файл | Назначение |
| --- | --- |
| `apply_custom_ui.bat` / `apply_first.ps1` | Установка / обновление патча и запуск фонового сервиса |
| `restore_original_ui.bat` / `restore_first.ps1` | Откат к оригинальному UI и удаление сервиса |
| `patch_asar.py` | Динамический патчер Electron `app.asar` (с пересчётом SHA-256 `integrity`) |
| `qusaCustomUI.js` | Логика кастомного интерфейса, тем, обоев и переименований |
| `qusa_watcher.ps1` / `start_watcher_hidden.vbs` | Скрытый фоновый сервис автообновления патча |
| `launch_medium.ps1` | Перезапуск Antigravity с Medium IL (сохраняет drag-and-drop) |
| `assets/` | Встроенные обои и примеры видео-фонов |
